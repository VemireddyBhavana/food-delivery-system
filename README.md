# 🍔 QuickBite - Food Delivery System

A modern and responsive **Food Delivery System** inspired by Blinkit, built using **HTML, CSS, and JavaScript**. This project allows users to browse food items, add them to the cart, place orders, and track delivery status without using any external APIs.

---

# 📌 Project Overview

QuickBite is a frontend food delivery application designed to provide a simple and user-friendly ordering experience. Users can browse popular dishes, manage their cart, place orders, and view simulated order tracking.

## 🚚 Track Order Page

Delivery Tracking Simulation without APIs.

Order Status Flow:

```
Order Confirmed
⬇
Preparing Food
⬇
Out For Delivery
⬇
Delivered
```

The delivery status updates automatically using JavaScript timers.
